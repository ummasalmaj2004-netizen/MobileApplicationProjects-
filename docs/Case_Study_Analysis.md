# Case Study Analysis – Calculator Application

## Problem Overview
Students often need a simple calculator to perform quick arithmetic operations.  
The challenge is to design and implement a mobile calculator application that is simple, reliable, and user-friendly.

---

## Implemented Solution
Our group is developing a mobile calculator app using **Kotlin** and **Android Studio**.  
The app is designed to:
- Perform addition, subtraction, multiplication, and division.  
- Provide a reset/clear function for convenience.  
- Feature a clean and intuitive user interface.  
- Follow the **MVVM architecture** for maintainability and scalability.

---

## Key Features
- Basic arithmetic operations (add, subtract, multiply, divide).  
- Clear/reset functionality.  
- Error handling (e.g., divide by zero).  
- Responsive and simple UI design.
